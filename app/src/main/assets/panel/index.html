Cara pakai dengan domain Cloudflare

  1. Login playit.gg, tambah agent tipe Docker, salin SECRET_KEY, tempel di atas lalu Start.
  2. Di dashboard playit, buat tunnel Minecraft Java ke 127.0.0.1:25565. Catat alamat dan port yang diberikan.
  3. Cloudflare DNS: record SRV name _minecraft._tcp.mc, priority 0, weight 5, port dari playit, target hostname playit. Biarkan DNS only (awan abu-abu).
  4. Teman join ke mc.domainkamu.com tanpa port.

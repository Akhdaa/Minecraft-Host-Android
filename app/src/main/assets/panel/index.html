Hubungkan akun playit.gg (gratis) supaya teman di luar WiFi bisa join. Cukup sekali, sekitar 3 menit.

  2. Tempel secret key agent di bawah
  3. Buat tunnel Minecraft Java ke 127.0.0.1:25565

Panduan tunnel & domain

Gratis. Bikin alamat internet supaya teman di luar WiFi bisa join. Cukup sekali.

  1. Buat akun. Buka playit.gg, pilih Create account, daftar pakai email, lalu verifikasi email dari inbox.
  2. Tambah agent. Di dashboard buka Agents > Add Agent, pilih tipe Docker. Beri nama, misal hp-server.
  3. Salin secret key. Playit menampilkan perintah docker berisi SECRET_KEY=.... Salin isi setelah tanda sama dengan saja.
  4. Tempel di app. Tab Tunnel > kolom Secret key agent > Simpan key > Start tunnel. Tunggu sampai status Aktif dan agent di dashboard jadi online.
  5. Buat tunnel. Dashboard playit > Tunnels > Add Tunnel:
    Tunnel typeMinecraft Java
    Agentagent yang tadi (hp-server)
    Local address127.0.0.1
    Local port25565
    Proxy protocolNone / off
    Lalu Create. Pilih tipe Minecraft Java, bukan TCP biasa, karena TCP dibatasi di paket gratis.
  6. Selesai. Dalam setengah menit alamatnya (misal xxx.joinmc.link) muncul di Beranda. Tekan Salin lalu kirim ke teman.
  7. Biar aman. Tab Konsol > kartu Pemain: nyalakan Whitelist, lalu tambahkan nama teman.

Opsional. Supaya teman join pakai domain sendiri, misal mc.domainkamu.com, bukan alamat playit. Butuh domain yang sudah ada.

  1. Masukkan domain ke Cloudflare. Login dash.cloudflare.com > Add a domain (Onboard a domain), ketik domain, pilih paket Free.
  2. Ganti nameserver. Cloudflare memberi 2 nameserver. Masuk ke tempat beli domain (registrar), ganti nameserver domain ke dua alamat itu. Tunggu sampai Cloudflare menyatakan domain Active (bisa beberapa menit sampai 24 jam). Lewati langkah ini kalau domain sudah aktif di Cloudflare.
  3. Buat API token. Ikon profil kanan atas > My Profile > API Tokens > Create Token > template Edit zone DNS > Use template.
    PermissionsZone · DNS · Edit
    + Add moreZone · Zone · Read
    Zone ResourcesInclude · Specific zone · domain kamu
    Continue to summary > Create Token > Copy. Token cuma tampil sekali, jangan dikirim ke chat atau orang lain.
  4. Isi domain di app. Tab Tunnel > kartu Domain Cloudflare: isi Domain untuk join (misal mc.domainkamu.com), pilih tunnel playit, Simpan.
  5. Pasang token. Buka Atur otomatis pakai API token Cloudflare, tempel token, Simpan token, lalu Buat / update record sekarang. Biarkan Update otomatis nyala.
  6. Cek. Tunggu 1 sampai 5 menit, tekan Cek DNS. Kalau status DNS benar, teman cukup join ke domain kamu tanpa port.
Tanpa token (isi manual)

Isi domain lalu Simpan. Di Cloudflare: domain kamu > DNS > Records > Add record, Type SRV, lalu salin Name, Priority, Weight, Port, dan Target dari kartu Domain Cloudflare. TTL Auto, Save. Kalau port playit berubah, record harus diupdate manual.

Jangan buat record A/CNAME dengan nama yang sama (misal mc) yang awan oranye, nanti domain nyasar.

Restart server supaya perubahan config dipakai.

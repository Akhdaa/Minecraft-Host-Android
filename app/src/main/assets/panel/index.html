Domain Cloudflare-

Cloudflare > domain kamu > DNS > Records > Add record, isi persis seperti ini:

Form lama dengan kolom Service/Protocol: Service _minecraft, Protocol TCP, Name diisi subdomain saja. Jangan ada record A/CNAME dengan nama sama yang awan oranye.

Atur otomatis pakai API token Cloudflare
  1. Cloudflare > ikon profil > My Profile > API Tokens > Create Token.
  2. Pilih template Edit zone DNS. Zone Resources: Include, Specific zone, pilih domain kamu.
  3. Continue to summary > Create Token, salin token, tempel di bawah.
Update otomatis
Kalau alamat atau port playit berubah, record SRV ikut diperbarui saat panel terbuka

Token hanya disimpan di HP ini dan cuma dipakai ke api.cloudflare.com.

#### Сервер
- **Один APK, без Termux.** OpenJDK 17, 21 и 25 для Android уже внутри APK; нужная версия выбирается под версию Minecraft.
- **Несколько серверов.** Модовый мир 1.20.1 рядом с выживанием на Paper 1.21, переключение в одно касание (работает один за раз).
- **Шесть типов серверов:** Paper, Purpur, Fabric, Forge, NeoForge и Vanilla, Minecraft **от 1.17 до последней** (NeoForge — с 1.20.2).
- **Мастер создания сервера:** выбери ПО, версию, имя и ОЗУ, прими EULA — готово.
- **Старт, стоп, перезапуск, принудительная остановка** и автоперезапуск при сбое.
- **Сон, когда пусто (по желанию):** сервер останавливается через N минут без игроков и сам просыпается, когда кто-то заходит; адрес не меняется.
- **Ежедневный перезапуск (по желанию)** в выбранное время, с отсчётом в игре.
- **Создание из сборки Modrinth (.mrpack):** загрузчик, серверные моды и конфиги за один шаг.
- **Работает в фоне** через foreground-сервис, wake lock и Wi-Fi lock; может запускаться при открытии приложения или включении телефона.

#### Моды и мир
- **Магазин Modrinth** в приложении: моды, плагины и датапаки под версию сервера, сортировка, категории, зависимости ставятся автоматически.
- **Пакет оптимизации для телефона** (Fabric) в одно касание: Lithium, FerriteCore, Krypton, ModernFix, Chunky.
- **Управление модами/плагинами:** поиск, включение, выключение, удаление, загрузка `.jar`, с настоящими названиями и иконками из Modrinth.
- **Обновление модов в одно касание:** видно, для каких модов есть новая версия под твой сервер; обнови один или все.
- **Бэкап и восстановление** с прогрессом, автобэкапы во время работы сервера, загрузка мира с ПК, скачивание бэкапов.
- **Файлы мира:** обзор папки сервера, размеры Верхнего мира/Незера/Края, скачивание, загрузка, переименование, удаление.
- **Редактор конфигов** для `.toml`, `.json`, `.properties` и подобных файлов, плюс форма `server.properties` с подсказками.
- **Сброс только Незера или Края**, не трогая Верхний мир.
- **Полный бэкап сервера (по желанию):** мир плюс моды, плагины и конфиги; восстанови целиком, сделай новый сервер или импортируй архив папки сервера.

#### Панель
- **Веб-панель** на порту `8080` — внутри приложения (WebView) или в любом браузере в той же Wi-Fi.
- **Английский, индонезийский, китайский и русский**, с туром по всем экранам при первом запуске.
- **Живая консоль** с фильтрами уровней, поиском, историей команд, быстрыми командами и кнопками сложности.
- **Управление игроками:** OP, белый список, режим игры, лечение, кик, бан, разбан.
- **Состояние телефона:** ОЗУ сервера, аптайм, заряд и температура батареи.
- **Уведомления (по желанию):** сервер готов, упал, уснул или проснулся, игроки заходят и выходят, телефон перегрелся.
- **Вход по PIN** с других устройств; после 3 неверных попыток вход временно блокируется.
- **Бэкап настроек:** сохрани настройки приложения (PIN, секрет playit, домен и токен Cloudflare) и восстанови их после переустановки или на новом телефоне.
- **Удобно** и на телефоне, и на компьютере.

#### Игра через интернет
- **Встроенный туннель playit.gg** (playitd собран для Android), бесплатно.
- **Игроки Bedrock (по желанию):** один переключатель ставит Geyser + Floodgate под версию сервера, чтобы заходили с телефонов и консолей.
- **Адреса на вкладке «Сервер»:** скопируй и отправь друзьям.
- **Свой домен через Cloudflare:** SRV-запись вычисляется, проверяется и может создаваться автоматически по API-токену.
- **Пошаговые инструкции** для playit и Cloudflare на вкладке «Туннель».

<h1><a id="download"></a>Скачать</h1>

Скачай последний `MCHost-1.0.x.apk` на странице [**Releases**](../../releases/latest). Каждый пуш в `main` собирает новый APK через GitHub Actions.

</div>

**Установка на телефоне:** открой APK и разреши «Установку неизвестных приложений». Android скажет, что приложение создано для старой версии — это нормально (см. [FAQ](#faq)).

**Установка через ADB:** запусти [`install-mchost.bat`](install-mchost.bat) на ПК с телефоном, подключённым по USB-отладке. Скрипт скачает последний APK, установит или обновит его, отключит оптимизацию батареи и откроет приложение. Или вручную:

```bat
adb install -r --bypass-low-target-sdk-block MCHost-1.0.x.apk
adb shell dumpsys deviceidle whitelist +com.minecrafthost.id
```

Обновления всегда безопасны: миры, моды и настройки сохраняются, потому что все сборки подписаны одним ключом.

**Установка на Windows:** скачайте `MCHost-1.0.x.msi` с той же страницы [Releases](../../releases/latest) и запустите. Установка только для вашей учётной записи, права администратора не нужны. Не хотите установщик? Распакуйте `MCHost-1.0.x-portable.zip` куда угодно и запустите `MC Host.exe`.

- Windows 10 или 11, 64-бит. Панель открывается в отдельном окне (используется WebView2, он есть в Windows 11 и в актуальной Windows 10).
- Закрытие окна не останавливает сервер: MC Host остаётся в трее. Для выхода нажмите правой кнопкой на значок в трее, сервер сначала корректно остановится.
- Java скачивается, когда она впервые понадобится серверу, ставить ничего больше не нужно. Данные лежат в `%LOCALAPPDATA%\MCHost`.
- Windows SmartScreen может предупредить об установщике, так как он пока не подписан: нажмите **More info**, затем **Run anyway**.
- При первом запуске сервера брандмауэр Windows спросит про `java.exe`. Разрешите **частные сети**, чтобы друзья из вашей Wi-Fi могли зайти.
- Перенос между телефоном и ПК: включите полный бэкап сервера в Настройках и используйте **Импорт сервера** на другом устройстве.
- Перетащите `.jar` на панель, чтобы установить его как мод или плагин, или `.zip`, чтобы импортировать сервер или восстановить бэкап мира.

<h1><a id="start"></a>Быстрый старт</h1>

</div>

1. Открой **MC Host**, разреши уведомления, выбери язык. Короткое знакомство и тур покажут, что где находится.
2. Нажми **+**, чтобы создать сервер: выбери ПО (Paper — для плагинов, Fabric/Forge/NeoForge — для модов), версию Minecraft, имя и ОЗУ (телефон на 8 ГБ: 3–4 ГБ) и прими EULA. ПО сразу начнёт скачиваться.
3. Сервер на Fabric? Открой **Моды > Магазин Modrinth** и нажми **Установить все** на пакете оптимизации.
4. На вкладке **Сервер** нажми **Старт**. Первый запуск дольше, потому что создаётся мир.
5. Друзья в той же Wi-Fi заходят по адресу **LAN** с вкладки «Сервер».
6. В **Настройках** нажми **Отключить оптимизацию батареи**, затем включи **Автозапуск** в сведениях о приложении (MIUI/HyperOS), чтобы Android не убивал сервер.

Чтобы открыть панель с ПК, введи адрес **PANEL** в браузере (например `http://192.168.1.36:8080`) и PIN из **Настройки > Доступ к панели**.

<h1><a id="tunnel"></a>Игра через интернет</h1>

</div>

Полная инструкция с картинками есть в приложении: **Туннель > Помощь**. Коротко:

| Шаг | playit.gg (обязательно, бесплатно) | Cloudflare (необязательно) |
|---|---|---|
| 1 | Зарегистрируйся на [playit.gg](https://playit.gg), добавь агента типа **Docker**, скопируй его `SECRET_KEY` | Твой домен активен в Cloudflare |
| 2 | Вставь его на вкладке **Туннель**, **Сохранить и подключить**, **Start tunnel** | Создай API-токен по шаблону **Edit zone DNS** + право **Zone · Read** |
| 3 | В панели playit: туннель **Minecraft Java** на `127.0.0.1:25565` | Введи домен и токен в карточке **Домен Cloudflare** |
| 4 | Адрес появится на вкладке **Сервер**, нажми «Копировать» | **Обновить запись сейчас**, затем **Проверить DNS** |

После этого друзья заходят на `xxx.joinmc.link` или `mc.yourdomain.com`. Включи **белый список** на вкладке «Консоль», чтобы заходили только друзья.

<h1><a id="faq"></a>FAQ</h1>

</div>

<details>
<summary><b>Почему Android пишет, что приложение создано для старой версии?</b></summary>

`targetSdk` специально равен 28. Android разрешает приложению запускать программы из своей папки данных (здесь `java` и `playitd`) только если оно нацелено на API 28 или ниже; Termux делает так же. На Android 14 и новее, если установка заблокирована, используй `adb install --bypass-low-target-sdk-block`.
</details>

<details>
<summary><b>Нужен ли root?</b></summary>

Нет. Всё работает без root, а на рутованных телефонах (Magisk / KernelSU) приложение работает как обычно без выдачи root. Root помогает только вне приложения, например чтобы Android не убивал сервер при нехватке ОЗУ или для настройки CPU governor.
</details>

<details>
<summary><b>Могут ли зайти друзья с пиратским Minecraft?</b></summary>

Да. В **Мир > Настройки** выключи **Online mode**, затем включи **белый список** и добавь друзей на вкладке «Консоль». Без белого списка любой сможет зайти под чужим ником.
</details>

<details>
<summary><b>В логе пишет "moved too quickly", хотя я просто бегу</b></summary>

Это проверка движения в ванильном Minecraft, а не баг. Если соединение (например, через туннель playit) подвисает на секунду-две, твои перемещения приходят разом и выглядят как прыжок больше чем на 10 блоков, поэтому сервер слегка возвращает тебя назад. Игра по адресу LAN этого избегает. Если в логе есть ещё и "Can't keep up!", значит перегружен сам телефон.
</details>

<details>
<summary><b>Сервер лагает или телефон греется?</b></summary>

Поставь пакет оптимизации, снизь *дальность прорисовки* до 5–6, заранее сгенерируй мир командами `chunky radius 1000` и `chunky start` и используй Wi-Fi вместо мобильного интернета. Для серверов с большим количеством модов не играй и не хости на одном и том же телефоне.
</details>

MC Host предназначен для законного личного использования: игры с друзьями, изучения того, как работают серверы, и экспериментов на своём устройстве.
